## How I work

- **Metrics defined before the numbers.** The denominator decides whether a figure can be compared with anything.
- **Every difference tested, then sized in money.** On large samples almost everything is significant; the effect on revenue is what matters.
- **Findings end in decisions.** Each analysis closes with recommendations ranked by expected impact.

## Featured projects

### Analytics

#### [Payment Transactions Analysis](https://github.com/Nujabesuuu/Payment_analysis)
`SQL` `DuckDB` `BigQuery` `SciPy` `Matplotlib`

End-to-end analysis of 237K card payment attempts: approval rate, chargebacks, revenue and cohort LTV, with every finding tested for significance and sized in money.
**Result:** Android approves 7.4 pp below desktop, worth about 4.2% of net revenue; the ceiling on recoverable revenue is 20.7%.

#### [COVID-19 Data Analysis](https://github.com/Nujabesuuu/covid-sql-tableau-analysis)
`SQL` `CTEs` `Window functions` `Tableau`

SQL data cleaning and exploration, followed by an [interactive Tableau dashboard](https://public.tableau.com/app/profile/eugene.opria/vizzes).
**Result:** global KPIs, a choropleth infection map, and country trends with forecast bands.

### Machine learning

#### [Customer Churn Prediction](https://github.com/Nujabesuuu/Churn_rate_prediction_deploy)
`scikit-learn` `LightGBM` `Streamlit` `Docker`

The full ML lifecycle for 72K subscribers, from EDA to a Streamlit app in Docker.
**Result:** ROC-AUC 0.982, F1 0.947. Found and removed target leakage before training.

#### [Air Raid Alert Forecasting](https://github.com/Nujabesuuu/AlarmForecast) · *team project* [live demo](https://alarm-forecast.vercel.app)

A production system that forecasts alerts 24 hours ahead for 25 Ukrainian regions. **My part:** the data pipeline, NLP features, baseline models and the frontend map.
**Result:** 385K Telegram messages turned into 20 hourly features; baseline F1 of 0.67–0.68.
